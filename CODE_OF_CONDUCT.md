# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good intent, and focus on what is best for the project and
its users. Harassment and personal attacks are not tolerated.

Report unacceptable behaviour privately to a maintainer (see [MAINTAINERS.md](MAINTAINERS.md)).
Reports are handled confidentially.
